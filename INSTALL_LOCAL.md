# Install Apollo Media Server 0.1.3 on Home Assistant OS/Supervised

This ZIP is a Home Assistant local add-on repository source, not a Kodi add-on.

1. Extract the archive.
2. Copy the `apollo_media_server` folder into Home Assistant `/addons/`.
3. In Home Assistant go to Settings -> Add-ons -> Add-on Store.
4. Open the menu and choose **Check for updates** / reload the store.
5. Under **Local add-ons**, install **Apollo Media Server**.
6. Start it and enable **Show in sidebar**.
7. Open Apollo Media from the sidebar.

For a public release we will publish the repository so users can add a repository URL
instead of copying files manually.
