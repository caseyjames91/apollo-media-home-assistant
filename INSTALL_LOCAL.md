# Apollo Media Server installation

Preferred development and update path is the Home Assistant add-on repository:

`https://github.com/caseyjames91/apollo-media-home-assistant`

Apollo Media Server uses persistent add-on storage for `/config/apollo.db`, so application updates preserve integration/profile/catalog state.

For repository development, future update ZIPs can be applied from the Git repository root with `release-update.sh`.
